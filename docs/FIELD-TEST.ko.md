# 현장 측정 절차

이 앱이 실제 교실에서 얼마나 잡고 얼마나 놓치는지는 아직 측정하지 않았습니다([README](../README.md#상태)). 이 문서는 그 수치를 **서로 비교할 수 있게** 재는 절차입니다. 측정 결과는 실기기 결과 이슈로 올립니다(#38 의 양식이 들어오면 그 양식을 씁니다).

측정 결과는 "이 조건에서 이만큼 잡혔다"는 기록이며, 다른 교실·기종·기기에서도 같다는 뜻이 아닙니다.

## 준비

- **측정 기기:** 앱을 실행할 휴대폰이나 태블릿. 모델, Android 버전, 앱 버전(또는 커밋)을 적습니다. 여러 대를 비교하면 각각 적습니다.
- **기준 기기:** 아래 종류마다 한 대 이상. 제품 이름과 상태를 적습니다.

  | 종류 | 상태 예 |
  | --- | --- |
  | 무선 이어폰 | 케이스 열림(연결 전), 휴대폰과 연결됨 |
  | 스마트워치 | 휴대폰과 연결됨 |
  | 스마트 안경·카메라 안경(있으면) | 대기, 촬영 직후 |
  | 휴대폰 | 블루투스만 켬, 핫스팟 켬 |

- **장소:** 실제 시험에 쓰지 않는 빈 교실. 크기(대략 가로×세로 m), 벽 재질, 옆 교실 사용 여부를 적습니다. 실제 시험 중에는 측정하지 않습니다.
- 기록에 이름·주소·장소 이름이 들어가지 않게 합니다. 화면을 첨부할 때는 가립니다.

## 측정

### 1. 빈 교실 기록

기준 기기를 모두 끄거나 교실 밖에 둔 채 측정 기기 위치를 정하고 빈 교실을 기록합니다. 측정 기기 위치(예: 교탁, 교실 뒤 가운데, 감독관이 들고 서 있음)를 적습니다.

### 2. 탐지율

기준 기기 하나를 아래 조건에 두고 켠 뒤, **60초 안에** 새 전파로 뜨는지 봅니다. 뜨면 걸린 시간도 적습니다. 끄고 1분 기다린 뒤 다시 켜서 **조건마다 10회** 반복합니다.

- 거리: 측정 기기에서 1 m, 3 m, 6 m, 교실 끝
- 가림: 책상 위(가림 없음), 주머니나 가방 안, 사람 몸 뒤

결과는 조건마다 "10회 중 n회, 평균 t초"로 적습니다. 횟수가 적은 수치는 크게 흔들리므로 비율만 쓰지 말고 횟수를 함께 적습니다.

### 3. 오탐

기준 기기 없이 **30분** 그대로 둡니다. 새 전파 개수가 몇 번, 언제 늘었는지 적습니다. 복도 통행, 옆 교실 사용처럼 그 사이에 있던 일도 적습니다.

### 4. 배치 비교 (여러 대일 때)

같은 조건에서 측정 기기 위치나 대수만 바꿔 2번과 3번을 되풀이합니다. 예: 감독관 폰 한 대(교실 앞) / 고정 기기 한 대(교탁) / 고정 기기 두 대(교탁 + 교실 뒤, 둘 중 하나라도 뜨면 잡힌 것으로 셈).

## 적을 때 주의

- **못 잡은 것도 적습니다.** 끝까지 뜨지 않은 조건이 가장 중요한 결과입니다.
- 알림 신호를 내지 않는 기기(블루투스·와이파이를 끈 기기, 연결 뒤 알림을 멈추는 기기)는 이 절차로 잡히지 않는 것이 정상입니다. "잡히지 않음"으로 적고, 앱의 오류로 보지 않습니다.
- 측정하지 않은 조건은 측정하지 않았다고 적습니다.
